# 💱 Conversor de Moedas Dinâmico

Este projeto é uma ferramenta prática de conversão de moedas, focada em fornecer uma interface limpa e uma experiência de uso intuitiva. Desenvolvido para aplicar conceitos de lógica de programação e manipulação de DOM.

 <img width="1911" height="955" alt="convmoedas" src="https://github.com/user-attachments/assets/8d69f9de-ab4d-405e-8ae4-52bc48c015c4" />

## 🚀 Tecnologias Utilizadas
- **JavaScript (ES6+):** Utilizado para a lógica de conversão e atualização dinâmica de elementos.
- **HTML5:** Estruturação semântica do projeto.
- **CSS3:** Estilização moderna com foco em responsividade e design intuitivo.

## 🛠️ Desafios e Aprendizados
Durante o desenvolvimento deste projeto, foquei em:
1. **Lógica de Conversão:** Implementação de cálculos precisos baseados em taxas fixas (ou dinâmicas via API).
2. **Manipulação de DOM:** Atualização em tempo real de textos, imagens de bandeiras e valores sem a necessidade de recarregar a página.

## 📦 Como visualizar o projeto
Você pode visualizar o resultado final rodando o arquivo `index.html` em seu navegador ou acessando o link do GitHub Pages (se disponível).
